# Приёмка UI
Проверить карту на весь экран: на мобильном поиск находится в нижней раскрываемой панели, на desktop — слева. «Карта» сворачивает список, «Список» раскрывает его; карта остаётся видимой. Метки и выбранный объект вписываются в свободную область с учётом панелей и навигации. Ручное перемещение не сбрасывается при изменении панели; «Показать все объекты» возвращает всю выдачу. В интро карта приглушена и недоступна для управления, после интро сохраняет тот же экземпляр; шапка видна на всём интро без размытия и получает backdrop blur после появления полной карты; нижняя навигация скрыта до конца интро; reduced motion сразу открывает поиск. Масштаб на API-карте — через кнопки приложения, не через стандартный UI Яндекса. Без API-ключа iframe показывает географию и обычные метки выдачи с резервом под панели; выбор объекта по метке и цены требуют ключа.

1. Reset demo → поиск без дополнительных фильтров. Явно выбрать до 6000 и вид на море при 12–16 июня 2027 и 2 гостях: только «Терраса над Ялтой», 4200/ночь, 16800 итог.
2. Открыть пин или строку списка → превью-карточку (панель результатов остаётся открытой) → объект по повторному клику на ту же метку/строку, по карточке или по стрелке в строке: тот же id, цена, фото и выбранные даты. Back возвращает фильтры и карту. Кластер показывает локализованный счётчик («N объекта/ов») и карточки с фото; открытие кластера закрывает одиночное превью.
3. Убрать фильтры: видны опубликованные объекты. Черновик доступен только host1. Хостел появляется при 1 госте.
4. В Кипарисе №101 недоступен 12–16, доступен начиная с 15 июня. №202 закрыт до 20 июня. №102 свободен.
5. Забронировать p1 на 12–16: pending_host, повторная бронь пересекающихся дат отклоняется. Подтвердить хозяином, симулировать оплату гостем; статус в обеих ролях совпадает.
6. Отменить до заезда: даты снова доступны. Нельзя менять занятые даты блокировкой без ошибки конфликта.
7. Избранное и брони переживают reload. Reset возвращает исходный сид. Не очищается чужой localStorage.
8. 360/390/430/768/1440px: CTA доступен, клавиатура не закрывает поля, safe areas, нет горизонтального скролла всей страницы.
9. Empty (цена до 500), загрузка, ошибка+retry; фокус клавиатуры, reduced motion, длинное название, отсутствие фото.
10. Unit-тесты Vitest: даты, границы, отмены, ремонт, цена, вместимость, публикация, конфликт брони. Component-тесты Vitest+Vue Test Utils: применение/сброс фильтра, выбор unit, изменение статуса, сохранение repository. Не подменять ручную UI-проверку snapshot-тестами.

11. Nuxt: прямой заход на /stays/p1 отдаёт название и описание в серверном HTML; /locations/yalta фильтрует город. Неверный id/slug даёт 404.
12. После reload сохранённая бронь восстанавливается после mount без hydration mismatch и без перезаписи localStorage. Другой браузер получает исходный seed.
13. /tg без Telegram SDK работает в браузере; карта загружается только клиентом; server build не падает на window/localStorage. Пройти typecheck и production build.
14. Старые стартовые ограничения до 6000 и вид на море снимаются при восстановлении неизменённого пресета; изменённые фильтры, объекты и брони сохраняются. Исходная запись остаётся в резервной копии до сброса демо. Проверить повторный reload без повторного изменения данных; правила и откат — в [сценариях показа](DEMO.md#storage-upgrade-and-rollback).
15. Статическое превью: после `npm run generate` проверить прямой вход и reload на `/tg/search/`, `/stays/p1/` и `/tg/host/calendar/`, затем переходы между web и Mini App. Завершающий `/` не вызывает ошибку экрана. Существующие публичные страницы содержат HTML сида; query-фильтры применяются в браузере. Для неизвестного маршрута проверять клиентский экран 404: Apache fallback может отвечать HTTP 200. Карта, изображения и приватные экраны должны загружаться с опубликованного домена; инструкция — [публикация](DEMO.md#preview-publication).

16. Панели поиска: редактирование цены/дат не меняет выдачу и URL до применения; закрытие и Escape отменяют черновик. Пустая цена означает отсутствие ограничения. Неверные даты и гости дают ошибку у поля; для долгосрока минимум 30 ночей. «Заезд сегодня» включается и выключается с возвратом прежних дат; в долгосроке скрыт и внутри всех фильтров не дублируется. Сброс и удаление меток сохраняют направление и поездку; круглая кнопка сброса рядом с «Все фильтры» доступна без раскрытия панели. На 390/430 px действия панели доступны над навигацией, количество результатов видно; после применения показана выдача/карта, Back из объекта возвращает позицию и выбранную метку. Проверить общий бюджет на экране объекта и сохранение параметров через reload и /tg/search.
17. Интро на 360/390/430 px в портретной ориентации: в начальной фазе боковые колонки полностью видны и примыкают к краям экрана без внешних полей; фотографии не искажены. При прокрутке вперёд и назад плитки не перекрываются; в конце разъезда ни одна фотография не остаётся у краёв экрана, а панель поиска сразу кликабельна. После смены ориентации геометрия пересчитывается; desktop сохраняет квадратные плитки, при reduced motion поиск доступен сразу.
